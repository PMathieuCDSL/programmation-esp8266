Comment faire ?
1. Faites glisser un bloc dans la zone centrale.
2. Cliquez sur un bloc MAX7219 pour dessiner le motif à droite.
3. Ajoutez des délais entre les motifs.
4. L'ordre des blocs correspond à l'ordre d'exécution.
5. Utilisez Répéter pour créer une boucle Arduino.
6. Utilisez DigitalRead et DigitalWrite pour les entrées/sorties.
7. Créez des variables et faites des calculs.
8. Glissez Définir une fonction directement dans la section Fonctions.
9. Copiez ensuite le code dans Arduino IDE.

⋮⋮ = déplacer un bloc • La zone entre deux blocs s’agrandit lorsque vous arrivez dessus.

Code Arduino généré

Le code est volontairement simple : chaque matrice est regroupée séparément et chaque DEL est représentée par un octet binaire.
Code copié !

Éditeur du bloc

Sélectionnez un bloc MAX7219 dans le programme pour dessiner son motif dans les quatre matrices.
Dans cette première version, le bloc Répéter est généré comme une boucle Arduino. Pour placer plusieurs actions à l'intérieur de la boucle, utilisez le bouton d'insertion prévu dans le programme.
Exemple : SI D8 est à HIGH ALORS. D8 sera configurée comme entrée numérique.
Placez les blocs d'action après ce bloc. La prochaine version pourra les regrouper automatiquement dans la fonction.
