Comment faire ?
1. Faites glisser un bloc dans la zone centrale.
2. Cliquez sur un bloc MAX7219 pour dessiner le motif à droite.
3. Ajoutez des délais entre les motifs.
4. L'ordre des blocs correspond à l'ordre d'exécution.
5. Utilisez Répéter pour créer une boucle Arduino.
6. Utilisez DigitalRead et DigitalWrite pour les entrées/sorties.
7. Créez des variables et faites des calculs.
8. Glissez Définir une fonction directement dans la section Fonctions.
9. Copiez ensuite le code dans Arduino IDE.

Éditeur du bloc

Sélectionnez un bloc MAX7219 dans le programme pour dessiner son motif dans les quatre matrices.

↔️ Faire défiler le motif

Le motif dessiné ci-dessus est déplacé sur les 4 matrices comme un seul écran de 32 × 8 DEL.
